### HomeCare AI

<em>Team Project · 5인 팀 / 팀장</em>

**수리 전에 필요한 정보를 하나의 상담 흐름으로**

세탁기·건조기·냉장고·식기세척기의 증상과 오류코드를 입력하면 제조사 자료를 바탕으로  
자가점검, 보증기간, 참고 수리비를 안내하고 공식 A/S 접수 경로를 연결하는 AI 상담 서비스입니다.

서비스·DB 설계와 Agent·MCP·RAG 개발을 맡고 전체 조율과 통합을 주도했습니다.  
금액과 조치 내용이 임의로 바뀌지 않도록 AI가 근거 ID를 선택하고 서버가 검증 후 원문을 복원하도록 구성했습니다.

[Repository](https://github.com/Sjoneon/AX_core_project) · [서비스 바로가기](https://homecare-omega-eight.vercel.app/)

### DaySync

<em>Personal Project · 1인 개발</em>

**하루를 시작할 때 필요한 정보를 한곳에서**

여러 앱에 흩어진 일정·교통·날씨 정보를 한곳에 모아 하루의 준비를 돕는 Android 앱입니다.  
이동 경로와 날씨를 확인하고, 자연어로 일정과 알람을 등록할 수 있습니다.

Android 앱과 FastAPI 서버, 외부 API 연동 및 AWS 배포를 맡았습니다.  
Gemini Function Calling으로 일정·알람 항목을 추출하고 서버의 필수값 검증을 통과한 요청만 저장하도록 구성했습니다.

### SOS Renewal

<em>Personal Project · 1인 개발</em>

**쇼핑몰의 화면과 서버 구조 전환**

Spring Boot·Thymeleaf 기반 쇼핑몰을 React SPA와 REST API 구조로 전환한 프로젝트입니다.  
기존 서비스 로직과 세션 인증을 재사용하고 화면 상태 관리와 서버의 인증·데이터 검증 책임을 분리했습니다.

상품 검색·장바구니·주문 API를 구현하고 공개 응답에서 재고 수량과 판매자 식별자를 제외했습니다.  
AWS EC2·RDS·S3로 배포 환경을 구성하고 CloudFront·WAF 운영 경험을 정리했습니다.

[Repository](https://github.com/Sjoneon/Style-of-Simplicity-renewal)
